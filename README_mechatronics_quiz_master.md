### CTE213 – Mechatronics Assignment

**Author:** OGUNWALE AL-AMEEN OLAWALE

## Project Description
Mechatronics Quiz Master is a Python-based quiz application designed to test students' knowledge of Mechatronics, electronics, robotics, automation and computer programming.

## Features
- 12 multiple-choice questions.
- Two attempts per question.
- Helpful hints.
- Automatic score calculation.
- Grading and performance remarks.
- Interactive menu system.

## Python Concepts Used
- Functions
- Lists and Dictionaries
- Loops
- Conditional Statements
- User Input
- Exception Handling

## How to Run
1. Install Python 3.
2. Download the Python file.
3. Open your terminal.
4. Run:

```bash
python mechatronics_quiz_master.py
```
